Privacy policy

This instance of {{ app_name }} is a self-hosted bridge. It is not affiliated with Zepp Health, Amazfit, Intervals.icu, or Livelox.

What is stored

  • Your e-mail address (used only to send a one-time login code and to identify your account).
  • Encrypted Intervals.icu API key and Livelox OAuth tokens.
  • Sync settings (sports, duration filter, on/off).
  • A seven-day import log (activity title, sport, status). GPS files are not kept: they are downloaded, posted to Livelox, and discarded.

What is sent where

  • Intervals.icu is queried with the key you provided, to list and download your own activities.
  • Matching activity files are uploaded to Livelox with the OAuth token you granted (scope routes.import).
  • Login codes are sent by e-mail from the operator of this instance.

Access and deletion

You can disconnect Intervals.icu and Livelox in Settings. Disconnecting Livelox revokes the refresh token when possible. Ask the operator of this deployment to delete your account and encrypted secrets if you want them removed from the database.

Tokens at rest are encrypted with a host key that is not stored in git. Without that key, a database dump is not usable as login credentials.

Zásady soukromí

Tato instance {{ app_name }} je samostatně provozovaný most. Nesouvisí se Zepp Health, Amazfit, Intervals.icu ani Liveloxem.

Co se ukládá

  • E-mailová adresa (jen kvůli jednorázovému přihlašovacímu kódu a identifikaci účtu).
  • Šifrovaný API klíč Intervals.icu a OAuth tokeny Liveloxu.
  • Nastavení synchronizace (sporty, filtr délky, zap/vyp).
  • Sedmidenní protokol importů (název aktivity, sport, stav). GPS soubory se neukládají: stáhnou se, odešlou do Liveloxu a zahodí.

Kam data odcházejí

  • Intervals.icu se ptáme klíčem, který jste vložili, na seznam a stažení vašich vlastních aktivit.
  • Odpovídající soubory se nahrají do Liveloxu tokenem, který jste udělili (oprávnění routes.import).
  • Přihlašovací kódy posílá e-mailem provozovatel této instance.

Přístup a smazání

Intervals.icu a Livelox lze odpojit v nastavení. Odpojení Liveloxu ve vhodných případech zneplatní i obnovovací token. Smazání účtu a šifrovaných tajemství z databáze řeší provozovatel této instance.

Tokeny v klidu jsou šifrované klíčem na serveru, který není v gitu. Bez něj výpis databáze nestačí jako přihlašovací údaje.
